# FLAME 🔥
تشغيل المشروع (يتطلب Node.js 18+):

    npm install
    npm run dev        # للتطوير: http://localhost:5173
    npm run build && npm run preview   # نسخة الإنتاج (PWA يعمل فقط في هذه النسخة)

البيانات محفوظة في LocalStorage لهذا المتصفح فقط. استخدم التصدير/الاستيراد (صفحة الإحصائيات) للنسخ الاحتياطي.
